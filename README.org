* How to use

Add =nixmacs= to your =flake.nix= inputs:
#+begin_src nix
inputs = {
  nixmacs = {
    url = "github:yvnth/nixmacs";
    inputs.nixpkgs.follows = "nixpkgs";
  };
};
#+end_src

Apply =nixmacs='s =emacs-overlay= in your system's =nixpkgs.overlays=:
#+begin_src nix
nixpkgs.overlays = [
  nixmacs.inputs.emacs-overlay.overlays.default
];
#+end_src
